2. Сплит-скрин

Для каждого следующего ролика крупный план продолжается с того места, где закончился предыдущий. Если видео кончится — начнётся сначала. Звук берётся из основного ролика.

Левая часть — основной ролик

Правая часть — крупный план

Основной ролик
Крупный план

Итог — квадрат 1080×1080. Нулевой сдвиг ставит центр ролика в центр своей половины.

3. Оверлей

Короткий оверлей зациклится, длинный — обрежется по длине результата.

4. Экспорт

Результат: es1.mp4, es2.mp4, …

Для TikTok и Shorts — квадрат 1080×1080, как в готовом примере.

Минимум нагрузки: 1–2 ядра на склейку, кодирование около 50% GPU. Готовый файл сразу появляется в папке.

# Standoff 2 — продажа по запросу (Perfect Click, Android)

Скрипт для Android-приложения **[Perfect Click Автокликер](https://play.google.com/store/apps/details?id=com.kolodeev.perfectclick)** (разработчик Valerij Kolodeev).

Оба приложения работают **на одном телефоне**: Standoff 2 в фоне/на экране, Perfect Click запускает скрипт поверх игры.

## Что делает скрипт

1. Читает цену верхнего запроса на покупку (`от 10.00 G`) через OCR.
2. Если цена ? `MIN_PRICE` — нажимает **ПРОДАТЬ**.
3. Вводит цену и подтверждает продажу.

## Установка на Android

1. Установите **Perfect Click** из Google Play.
2. Откройте приложение и выдайте разрешения:
   - **Сервис доступности** — без него клики не работают.
   - **Поверх других приложений** — оверлей поверх Standoff 2.
3. Скопируйте код из `standoff2-sell-by-request.pc` в редактор скриптов Perfect Click.
4. Настройте координаты (см. ниже).
5. Запустите Standoff 2 ? маркет ? страница предмета.
6. В Perfect Click нажмите **Запуск** (плавающая кнопка останется поверх игры).

## Настройка координат на телефоне

Координаты зависят **только от вашего экрана** (разрешение, масштаб, ориентация). Готовых координат «для всех» нет — их нужно снять на своём устройстве.

В Perfect Click откройте **инструмент координат / пипетку** (в меню или руководстве пользователя внутри приложения), затем:

| Переменная | Куда навести в Standoff 2 |
|---|---|
| `priceTL`, `priceBR` | Углы прямоугольника вокруг **10.00 G** |
| `btnSell` | Кнопка **ПРОДАТЬ** (слева внизу) |
| `btnPriceField` | Поле ввода цены (после нажатия ПРОДАТЬ) |
| `btnConfirm` | Кнопка подтверждения **ПРОДАТЬ** в диалоге |
| `KEY_X[0]`…`KEY_X[9]` | Цифры 0–9 на игровой клавиатуре |
| `KEY_Y` | Общая Y-координата ряда цифр |
| `btnDot` | Кнопка точки `.` |
| `btnDel` | Кнопка удаления символа |

### Режим калибровки OCR

В скрипте поставьте:

```java
boolean CALIBRATE_ONLY = true;
```

Запустите скрипт на странице предмета. В логе Perfect Click каждую секунду будет строка:

```
OCR цена: 10.0 G
```

Если видите `0` — сдвиньте `priceTL` / `priceBR` точнее на число цены. Когда цена читается верно — поставьте `CALIBRATE_ONLY = false`.

## Параметры

| Параметр | Описание |
|---|---|
| `MIN_PRICE` | Не продавать дешевле этой цены (голда) |
| `CHECK_MS` | Как часто проверять цену запроса |
| `AFTER_SELL_MS` | Пауза после продажи |
| `CALIBRATE_ONLY` | Только проверка OCR, без продажи |

## Советы для Android

- Не сворачивайте Standoff 2 во время работы скрипта.
- Отключите энергосбережение для обоих приложений, чтобы телефон не убивал фоновые процессы.
- Яркость экрана держите постоянной — OCR чувствителен к контрасту.
- Сначала проверьте на дешёвом предмете.

## Если команды не работают

В некоторых версиях Perfect Click функции вызываются с префиксом `pfc.`:

- `click` ? `pfc.click`
- `getText` ? `pfc.getText`
- `sleep` ? `pfc.sleep`
- `log` ? `pfc.log`

Смотрите встроенное руководство в приложении (раздел «Справка» / примеры скриптов).

## Важно

Автоматизация может нарушать правила Standoff 2. Используйте на свой риск.
